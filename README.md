# dot.Sales White Label — Landing Page

Landing Page de alta conversão para captação e qualificação de agências de tráfego pago e performance interessadas no modelo **White Label da dot.Sales**.

## 🚀 Tecnologias

- **Framework:** [Next.js 14.2](https://nextjs.org/) (App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Ícones:** [Lucide Icons](https://lucide.dev/)
- **Design System:** dot.Sales (Verde institucional `#007A55`, menta, off-white, botões pill e tipografia Inter)

## 🎯 Arquitetura de Conversão

1. **Barra Superior:** Qualificação imediata para donos de agências.
2. **Header:** Logotipo com selo White Label e CTA com scroll suave.
3. **Hero Section:** Headline orientada à oportunidade econômica com formulário em destaque.
4. **Formulário Qualificador (2 etapas):**
   - **Etapa 1:** Cadastro do cliente (Nome, Instagram da agência, WhatsApp com máscara brasileira e e-mail).
   - **Etapa 2:** Perguntas qualificatórias (Clientes ativos, principal serviço e uso de CRM).
5. **Demonstração do CRM:** Interface interativa com abas de WhatsApp com rastreamento de origem, Pipeline comercial e Métricas de ROI.
6. **Como Funciona:** 3 passos para estruturar a nova linha de receita.
7. **Benefícios Estratégicos:** Foco em monetização da carteira, análise pós-lead e retenção contratual.
8. **Recursos de Produto:** Grid compacto com 7 diferenciais essenciais.
9. **Para Quem é Indicado:** Checklist de qualificação de público.
10. **FAQ:** Acordeão interativo com dúvidas frequentes.
11. **CTA Final:** Chamada para agendamento de apresentação sem compromisso.
12. **Footer:** Termos de Uso, Política de Privacidade e direitos autorais.

## 🛠️ Como Executar Localmente

### Pré-requisitos
- Node.js 18+ instalado
- npm ou yarn

### Instalação
```bash
# Instalar dependências
npm install

# Executar em modo desenvolvimento
npm run dev

# Ou compilar e executar o build de produção
npm run build
npm run start -- -p 3001
```

Acesse em seu navegador: `http://localhost:3000` (ou `http://localhost:3001`).
